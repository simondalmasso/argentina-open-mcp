01 / Exploración

Empezá por el territorio.

Buscá provincias, departamentos, municipios o localidades presentes en las capturas verificadas. La búsqueda consulta la API propia; no completa datos que todavía no fueron publicados.

¿Qué lugar querés consultar?

La geografía oficial permite identificar unidades territoriales sin depender solamente de cómo se escriben sus nombres.

Los resultados siempre muestran el identificador geográfico y el snapshot de origen.

Primero, saber qué se está mirando.

Una provincia no es lo mismo que un aglomerado, ni una serie mensual se compara automáticamente con una anual. La cobertura y las reglas importan tanto como el número.

02 / Origen y permisos

Las fuentes, sin letra chica.

Cada registro expone quién publica, qué alcance tiene y qué condiciones de uso fueron revisadas. Que una fuente esté registrada no significa que todos sus datos puedan redistribuirse.

03 / Versiones publicadas

Datos con fecha y huella.

Cada snapshot publicado es una captura inmutable, identificada por un hash. Así se puede saber qué versión alimentó una consulta y cuándo fue recuperada.

04 / Criterios

Confianza antes que volumen.

La plataforma prioriza la calidad de la evidencia y el uso correcto de cada dataset. No mezcla universos, no inventa series y no supone permisos que la fuente no concedió.

01 — PROCEDENCIA

El origen viaja con el dato.

Fuente, URL, licencia declarada, fecha de recuperación, período, transformaciones y hash cuando existe un snapshot.

02 — COMPARABILIDAD

Comparar solo lo comparable.

Universo, cobertura, frecuencia y nivel geográfico se explicitan. Las diferencias metodológicas no se esconden detrás de un gráfico.

03 — REUTILIZACIÓN

Permisos por conjunto.

La licencia se evalúa por dataset y artefacto. Las condiciones no verificadas limitan la publicación, aunque la fuente sea oficial.

05 / Para desarrolladores y agentes

Una base. Dos formas de acceder.

Argentina Open Data es la experiencia pública de exploración. La API REST y Argentina Open MCP ofrecen contratos compartidos para integraciones, automatizaciones y agentes. La web no depende de un asistente para ser útil.
